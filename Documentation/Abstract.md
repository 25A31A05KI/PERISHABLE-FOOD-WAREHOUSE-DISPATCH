
# ABSTRACT

The Perishable Food Warehouse Dispatch System is a Java-based application developed to manage perishable food products in a warehouse.

Food products such as milk, bread, fruits and vegetables have limited shelf lives. If these products are not dispatched before their expiry dates, they may become unsuitable for consumption and cause food wastage.

This project uses a custom Min-Heap data structure to prioritize food batches based on their expiry dates. The batch with the earliest expiry date receives the highest dispatch priority.

The system provides functionalities such as adding food batches, displaying available batches and dispatching food according to expiry priority.

The application is developed using Java and Object-Oriented Programming concepts. It demonstrates how data structures and algorithms can be applied to solve real-world warehouse management problems.

**Keywords:** Java, Min-Heap, Data Structures, Warehouse Management, Food Dispatch, Expiry Date.
